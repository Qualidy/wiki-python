    Quiz: Komposition, Mixins & MRO¶

    Quiz: Komposition, Mixins & MRO

    Prüfe zuerst die Modellierungsentscheidung, dann die MRO.

    1. Ein Auto hat einen Motor. Welche Beziehung passt besser?

    2. Ein AdminUser ist ein User. Welche Beziehung passt besser?

    3. Was ist ein Mixin meistens?

    4. Welche Methode/Property zeigt die Method Resolution Order einer Klasse? Schreibe den Ausdruck für die Klasse Report.

    5. Was bedeutet super() bei Mehrfachvererbung genauer?

    6. Welche Ausgabe entsteht bei class Duck(CanSwim, CanFly), wenn beide move() haben und CanSwim.move() 'swim' zurückgibt?

    7. Ein Course enthält Student-Objekte. Welche Beziehung passt besser?

    8. Ein ElectricCar ist ein Car. Welche Beziehung passt besser?

    9. Welche Aussagen zu Mixins sind sinnvoll?

    10. Welche Ausgabe entsteht bei class Duck(CanFly, CanSwim), wenn CanFly.move() 'fly' zurückgibt?

    11. Was ist das Diamond Problem?

    12. Welcher Eintrag steht am Ende fast jeder MRO?

    13. Welche Schritte helfen beim Lösen einer MRO-Aufgabe?

    14. Was ist ein Warnsignal gegen Vererbung?

    15. Welche Methode wird in einem InfoMixin oft genutzt, um Attribute auszugeben?

    16. Welche Ausgabe erzeugt der Code?

    class CanSwim:
    def move(self):
        return "swim"

class CanFly:
    def move(self):
        return "fly"

class Duck(CanFly, CanSwim):
    pass

print(Duck().move())

    17. Welche Ausgabe erzeugt der Code?

    class Parent:
    def setup(self):
        print("Parent")

class Left(Parent):
    def setup(self):
        print("Left")
        super().setup()

class Right(Parent):
    def setup(self):
        print("Right")
        super().setup()

class Child(Left, Right):
    def setup(self):
        print("Child")
        super().setup()

Child().setup()

    18. Welche Ausgabe erzeugt der Code?

    class InfoMixin:
    def info(self):
        return self.__dict__

class Book(InfoMixin):
    def __init__(self, title):
        self.title = title

print(Book("Python").info())
