    Testexam 5 (PCAP-31-03)¶

    Dieses Testexam dient als Pruefungssimulation fuer PCAP-31-03 und ist nach der offiziellen Gewichtung zusammengestellt.

    Verteilung der 40 Fragen:

    • 6 Fragen: Modules and Packages
    • 5 Fragen: Exceptions
    • 8 Fragen: Strings
    • 12 Fragen: Object-Oriented Programming
    • 9 Fragen: Miscellaneous

    Empfehlung:

    • 65 Minuten
    • ohne Hilfen
    • Auswertung erst am Ende
    PCAP Testexam 5 (PCAP-31-03)

    Pruefungssimulation mit 40 Fragen, 65 Minuten und PCAP-31-03 Gewichtung: 6 Module, 5 Exceptions, 8 Strings, 12 OOP, 9 Miscellaneous.

    Zeit: --:--

    1. Select all option(s) which returns a random number between 0 and 100?

    2. What is the output of the following code if spam.py is run?

print("spam", end=' ')
import ham

import eggs
print("ham", end=' ')
# eggs.py
print("eggs", end=' ')

    3. Select all option(s) to properly call the choice() and/or choices() function?

    4. What is the output of the following code?

    >>> import math
>>> math.factorial(3)

>>> math.sqrt(1)

    6. What is the output of the following code?

>>> math.hypot(2)

    8. What will happen if spam.py is run?
